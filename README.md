# ThreadSphere - 3D Interactive Clothing Store

An interactive, modern 3D e-commerce fashion storefront featuring 3D product visualization, animated interactions, dynamic filtering, responsive shopping cart, and smooth UI transitions.

```text

└── thread-sphere-3d-shop-main/
    ├── src/
    │   ├── components/  # Reusable UI widgets & 3D showcase elements
    │   ├── hooks/       # Custom React state hooks
    │   ├── lib/         # Utility functions
    │   ├── pages/       # Store routes & views
```

## ⚙️ Prerequisites & Setup

### Requirements
- Basic familiarity with `TypeScript`
- Git installed on your local machine

### Installation Steps
```bash
# 1. Clone repository
git clone https://github.com/JasminPeer/clothing_store.git
cd clothing_store/thread-sphere-3d-shop-main

# 2. Install dependencies
npm install
# or bun install

# 3. Start local development server
npm run dev
```
